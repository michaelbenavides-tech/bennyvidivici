# Security Policy

Please do not report vulnerabilities through public GitHub issues.

Send reports to `security@example.com` with reproduction steps, affected versions, and impact.

## Supported Versions

| Version | Supported |
| --- | --- |
| main | yes |

AI-SGP governs AI security and must itself be secure. The MVP includes Keycloak OIDC integration, role-aware API dependencies, signed MinIO downloads, immutable audit log records, upload validation, and evidence package hashing.
